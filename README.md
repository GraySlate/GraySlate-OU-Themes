# GraySlate's OpenUTAU Custom Color Themes
Custom color themes for OpenUTAU created by GraySlate.  Free for all to use.<br />
<br />
These are all the custom color themes I've created for OpenUTAU so far.  These themes are free to use for anyone who wants to.  Credit me for the base themes if you use them.<br />
<br />
Feel free to modify the themes you use!  If you would like to submit themes based on my UTAUs, feel free to get in touch!  I will update this repo with more themes as I think of ones to make.

# How To Use
Before using these themes or setting any other custom theme, make sure that OpenUTAU's release channel is set to **alpha.**  Set the release channel in Preferences > General.  This will ensure the best appearance of each theme.<br />
<br />
<img width="548" height="223" alt="image" src="https://github.com/user-attachments/assets/96dbd2be-0816-42ee-867a-40b8060c72de" /><br />
<br />
Download the desired theme's .yaml file and place it in OpenUTAU's Themes directory.  For me, this location is ``C:\Users\andth\OneDrive\Documents\OpenUtau\Themes``.<br />
<br />
<img width="667" height="305" alt="image" src="https://github.com/user-attachments/assets/b2d6829b-b278-4adb-97f1-fd5a5064bfc2" /><br />
<br />
Under Preferences -> Appearance, select the theme you want to use from the drop-down menu.<br />
<br />
**NOTE:** My themes and most other custom themes work best if you turn "Use track color in UI" off.<br />
<br />
